# ここに置いてあるのは結合mp3を作成するための素材音声ファイルと、RSSを発行する際に公開レポジトリにコピーするファイル

全てファイル名は固定

## 素材音声ファイル
- opening.mp3 番組の最初に挿入されるジングルやオープニングテーマ曲
- ending.mp3 番組の最後に挿入されるジングルやオープニングテーマ曲
- jingle_01 02 03.mp3 番組中のトピックとトピックの間に挿入されるジングル。3種類がランダムに挿入される。

## その他
- artwork.jpg ポッドキャストのアートワーク
- style.css ポッドキャスト公開サイトのスタイルシート
